# Teacher Guide: NLP Nexus AI

This document explains the app in simple terms for quick evaluation.

## 1. What this project does

NLP Nexus AI is a small Hugging Face based application with three tabs:

1. Sentiment Analysis
2. Spam Detection
3. Dataset Explorer

It uses:
- Dataset: ucirvine/sms_spam
- Sentiment model: distilbert/distilbert-base-uncased-finetuned-sst-2-english
- Spam model: mrm8488/bert-tiny-finetuned-sms-spam-detection

## 2. Tab-wise behavior

### A) Sentiment tab

Input: Any sentence or review text
Output: POSITIVE or NEGATIVE with confidence

Example:
- Input: I really liked this app.
- Output: POSITIVE

### B) Spam Detection tab

Input: SMS-like text
Output: Spam or Not Spam with confidence and reason

This tab uses a hybrid approach:
1. Rule-based check for obvious spam words like win, prize, free, claim, urgent.
2. If no strong spam keyword is found, model prediction is used.

This improves demo reliability for common spam sentences.

Example:
- Input: Congratulations! You have won a cash prize. Reply WIN now.
- Output: Spam (rule-based)

### C) Dataset Explorer tab

1. Show Random Sample: Displays one random row from sms_spam dataset.
2. Show Distribution: Displays Ham and Spam counts and percentages.
3. Generate Sample Table: Shows multiple random samples in table format.

## 3. Quick test script (for evaluation)

Run these in order:

1. Sentiment test:
- I absolutely loved this project.
- This is very frustrating and bad.

2. Spam test:
- Congratulations! You won a free prize. Reply WIN now.
- Hi, I will reach by 7 pm.

3. Dataset test:
- Click Show Random Sample
- Click Show Distribution
- Click Generate Sample Table

## 4. Notes

- The project is made for educational demo and assignment submission.
- Outputs are model-based and may vary on edge cases.
- Main goal is to demonstrate use of Hugging Face models, dataset, and deployment on Spaces.
